# History

Dated planning documents and phase reports, kept as a record of how the POC was built. They describe the state and
plans **at the time they were written** - several plans were changed or dropped later (for example the candidate
voice sample, sound classification and the integration with another proctoring system). The current behaviour is
described in the main [README](../../README.md), [architecture.md](../architecture.md) and
[frontend-walkthrough.md](../frontend-walkthrough.md).

| Folder / file | Contents |
|---|---|
| `audio-research/` | model research, detection strategy, evaluation plan, architecture options, AI detection plan |
| `implementation-plan.md` | the phase plan |
| `results/` | measured results per phase (pyannote benchmark, diarization, observations, pipeline verification, baseline) |
