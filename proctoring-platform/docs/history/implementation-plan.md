## Standalone suspicious-audio detection (Phases 7–13)

Scope (24 Nov 2026): this repository is a complete, standalone audio-proctoring application; there is no
integration with any other proctoring system. Design: [audio-research/](audio-research/integration-design.md).
Each phase ends with measured results; a capability that fails its evaluation stays disabled and is documented.

| Phase | Deliverable | Depends on | Verified by |
|---|---|---|---|
| **7. Standalone correction + baseline** | Docs corrected (this plan, architecture, research docs); all services start independently from a clean shell; one-command run script (`scripts/run-all.ps1`); baseline: full test suites + one real-microphone session | 1–6 | Suites green; real-mic run with N consecutive events recorded in `docs/results/` |
| **8. Rules followed throughout:
- No placeholder implementations for core functionality; no hard-coded AI results.
- Tests are reported with their real output; nothing is marked passed unless it was run.
- Standalone application: no dependency on any other proctoring system; no placeholder integrations.
- No model is called working until it has been tested on labelled recordings; licences and label maps are
  verified before use; CPU inference is the default; Whisper is never required.
- AI outputs are potential observations for human review, never a verdict of misconduct.
